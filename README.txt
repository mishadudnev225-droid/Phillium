RUS:Phillium — это проект по созданию полностью свободной среды для нового формата веб-сайтов .PHILL . Это позволяет использовать более широкий спектр языков программирования для написания веб-логики, чем в традиционном веб-дизайне, а также добиться более легковесного и ресурсоэффективного отображения веб-сайтов, сравнимого с производительностью нативных приложений. Проект Phillium предполагает создание браузера с поддержкой моего собственного формата языка разметки, предложенного в качестве альтернативы крайне устаревшим форматам HTML и CSS, разработанным в 1990-х годах и не предназначенным для масштабных и сложных задач современных веб-страниц. Этот совершенно новый формат, PCBML (Phill's Configurable Block Markup Language), разработан с использованием современных технологий, а также более продвинутой и универсальной структуры файлов веб-сайта.

ENG:Phillium is a project to create a completely free environment for the new .PHILL website format. This enables the use of a wider range of programming languages for writing web logic than in traditional web design, as well as achieving a more lightweight, resource-efficient website rendering experience similar to native performance. The Phillium project envisions creating a browser with support for my own markup language format, proposed as an alternative to the extremely outdated HTML and CSS formats, originally developed in the 1990s and not designed for the large-scale and complex purposes of modern web pages. This completely new format, PCBML (Phill's Configurable Block Markup Language), is developed using modern technologies, as well as a more advanced and universal website file structure.
